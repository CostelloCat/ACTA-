# ACTA — notes for Claude / ChatGPT

Trading desk web app. Dark terminal. Do not add diurna to the wordmark.

- Brand: **ACTA**. Line under the mast: *for the people by the people*
- Desk (`/`): cinematic Earth hero, session clocks 3-across, six-chart bundle
- Global News (`/news`): night-Earth background; country tab = that country's newsrooms, native language
- Calendar (`/calendar`): wireframe mesh background; date sheet explains the print vs the tape
- Crypto (`/crypto`): 7-day coin wire, refresh 60s, no fake live TV
- Levels on a book page pull from Yahoo Finance on click — don't invent numbers
- Live badges only when a stream is actually on air
- TradingView mini charts: use free-widget symbols (NASDAQ:QQQ, FOREXCOM:SPXUSD, CBOE:VIX, TVC:GOLD, TVC:USOIL, FX_IDC:USDX). NDX/TVC:VIX/TVC:DXY die in the embed.

Stack: TanStack Start, Vite, React, Tailwind v4. Dev: `npm run dev` on 8080.
